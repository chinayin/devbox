常见问题

macOS
安装后命令找不到？
安装完成后需要重新加载配置。运行以下命令，或者直接重新打开终端： 
source ~/.zshrc
安装时需要输入密码？
安装 Homebrew 和 Xcode 命令行工具时需要管理员密码，这是正常的。输入你的 Mac 登录密码即可（输入时不会显示字符）。
提示 "xcrun: error: invalid active developer path"？
需要安装 Xcode 命令行工具。运行： 
xcode-select --install
在弹出的窗口中点击「安装」，等待完成后重新运行脚本。
Windows
提示脚本无法运行？
Windows 默认禁止运行脚本。打开 PowerShell，执行以下命令允许运行： 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
然后重新运行安装命令。
需要管理员权限吗？
不需要。Scoop 安装在用户目录下，无需管理员权限。如果你以管理员身份运行，脚本会自动检测并全局安装。
Python 显示 "Microsoft Store" 版本？
Windows 会将 python 命令重定向到 Microsoft Store。脚本会自动安装真正的 Python 并覆盖这个行为。如果仍有问题，重新打开 PowerShell 即可。
通用
国内用户需要使用 --china 吗？
如果你没有代理，强烈建议使用 --china 参数。它会自动配置清华、淘宝等国内镜像源，下载速度会快很多。

如果你已经有代理（科学上网），可以不加这个参数。
如何检查安装状态？
运行 status 命令查看当前环境： 
# macOS
./devbox-mac.sh status

# Windows
.\devbox-win.ps1 status
